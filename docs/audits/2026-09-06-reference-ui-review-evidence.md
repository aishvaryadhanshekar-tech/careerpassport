# Reference-direction UI review (source + existing screenshots)

Direction supplied by parent from Figma: cool slate/white surfaces, dark navy type, amber current step, quiet section dividers, obvious preview versus editor, brand above navigation/account below. Impeccable operate-mode assessment: improve scan order and component consistency; preserve all copy, data, controls, journeys and node semantics. Evidence: App.tsx full route inventory, shared/family CSS and existing desktop route screenshots; no new browser round or UI edits.

## Cross-family fixes (highest payoff)
1. Palette is fragmented: base body uses warm brown #1f1b16/#5c5347, canvas green ink/surfaces, legacy slate controls and teal selection. Establish navy/slate text, pale cool gray workbench, white surfaces and quiet cool-gray borders across shared families. Keep semantic green success, amber attention/message, violet trip, blue activity rather than recoloring all status meanings.
2. Section hierarchy relies on boxed gray title strips (`.app-card-head`) and nested `.hire-card`/`.criterion-card` surfaces. Make editor section headers white/unboxed with a fine divider, title 15–16px semibold and 20–24px surrounding spacing. Keep true selectable cards/drag nodes visibly bounded.
3. Small metadata overuses uppercase/tracking at 10–11px (`.lab`, jobs th, summary stats, counts). Set 11–12px, modest tracking, slate-secondary; body and field label hierarchy 14/13px. Do not remove meaningful labels or change factual copy.
4. Standardize header title scale (~24px page / 18px inspector / 15px section), 8px controls, 10–12px surfaces, subtle offset shadows only on floating surfaces. Strong dark primary action; quieter secondary outlines.
